# 产品契约

Mox 0.1.0 是 Apple Silicon macOS 上的本机 MLX 模型工作台和推理服务，是源码原型。当前行为以本契约、[API 子集](API.md)及实际代码为准；验证范围见[首版验证记录](VALIDATION.md)。

## 获取、管理和测试

- 支持 Hugging Face、ModelScope，以及这两种协议的自定义来源/镜像。获取前展示精确 revision、必要文件和空间计划，不下载整个训练仓库。
- 安装固定 revision，不后台更新。新版本成功安装后切换当前引用，旧安装保留；失败不覆盖已提交快照。可显式选择旧版。
- 导入本地目录默认只读引用，移除引用不删除原文件；托管模型删除会删除 Mox 拥有的文件。运行、准备或删除中的模型不能被另一个入口绕过准入保障。
- 模型使用安装 UUID 或唯一 alias；UUID 形状 alias 合法且按 UUID 规范拼写查询，其他 alias 大小写敏感。与另一安装 ID 冲突时拒绝，不猜测身份。
- 已安装模型请求时自动加载，未安装的请求明确失败，不自动下载。固定模型禁止自动淘汰，但显式卸载仍须检查使用状态。
- 下载任务独立于页面和观察连接，支持暂停、继续、取消及显式清理。服务重开核对实际文件并恢复索引与任务；单个坏模型不阻断健康模型和服务探活。
- 默认模型工作台；模型详情进入“测试此模型”。测试历史位于测试区域，单次一个 GUI 活动生成，服务可接受多个客户端并有界排队。

## 生成、参数和历史

参数逐字段优先级：显式请求 > 单模型设置 > 当前 worker 启动覆盖 > 持久全局设置 > 产品默认。GUI 在编辑当前请求覆盖后重新解析实际值及来源，重连保留覆盖；恢复默认清除当前覆盖。预览失败保留输入并显示错误，不将旧预览当作有效结果。已发出的请求保留发送时的参数快照。修改模型默认值与当前请求覆盖是不同动作。保存失败保留草稿，配置冲突需重新读取后提交。

完整性校验、排队、加载和生成均属于请求生命周期。服务探活不等于模型已就绪。停止先显示“正在停止”，等待真实停止后才结束；共享校验不会因一个请求取消而中止。失联不自动重发生成，重连核对状态；重试只由用户触发。

GUI 保存会话、消息与每次尝试。重试新增回答，保留旧结果；浏览旧尝试不改变继续提问的成功分支。失败/取消不伪装成功。崩溃后未结束尝试标 interrupted，不自动重生成。保存失败保留内存回复并提供保存重试，不清空用户库；新请求不得越过未保存状态。

历史显示和存储查询有界分页，页面之外的磁盘数据不删除。生成上下文仍来自有效完整分支，超过已有输入/资源限额明确拒绝，不静默截断。

## 进程、网络和数据所有权

关闭窗口继续运行；退出 App 协调停止自己启动的 worker，活动任务须提示。外部前台服务由原启动者拥有，App 不停止其进程。一个数据根只允许一个服务所有者；版本/身份不匹配明确拒绝连接。

公开 API 默认关闭，单独 loopback 地址与 Keychain 密钥；管理 token 与公开 key 分离。公共请求无状态，不写入 GUI 对话，不执行客户端工具。API 支持文本、流式、真实 usage 和客户端工具往返的明确子集，详细字段见 [API](API.md)。

用户模型、对话与凭据按所有权保护。未发布实现没有历史行为兼容负担，这不授权删除用户数据。数据位置、备份和诊断见[数据说明](DATA.md)。

## 首版边界与后续方向

当前不提供 Responses、legacy completions、embeddings、LAN 监听、连续批处理、跨请求 prefix cache、模型转换、多模态推理或内置 agent。多模态和 Pi 集成是后续方向，第一版不放置假能力控件或通用插件框架。

工具调用仅向经固定 revision、权重/tokenizer 摘要验证的受管 Qwen3 安装开放；导入引用或名称相似不代表工具可用。没有“所有 MLX 模型均兼容”的承诺，未知架构/预算无法估算时明确拒绝。

提供源码、本地可构建 App 和手动 GitHub Draft 二进制流程；实验 App 明确为 ad hoc 签名、未公证。公开前须下载实际 Release 附件并由用户验收，工作流不自动公开。没有 Developer ID 签名、公证或 Homebrew 分发。部署目标 macOS 15 不等于已完成 macOS 15 真机验证；人工体验验收尚未完成。

## 自助诊断与资源评估

CLI `doctor` 与 App“环境诊断”共享结构化检查结果：稳定 ID、通过/警告/失败/跳过/超时/取消、原因和下一步建议。默认只读，检查运行平台、完整产物资源与版本、数据根及运行目录的实际读写/遍历权限、目录安全性与磁盘、现有服务身份/状态及公开 API；不启动 worker、自动修复、改凭据或删除/重建数据。独立运行不要求 Xcode、Swift 编译器或 Python。没有运行的检查显示跳过，公开 API 默认关闭属于正常配置。

完整性与来源连通性须显式选择模型/仓库，带逐项进度、期限和取消。服务未运行时仍完成本地检查，扩展检查明确跳过。模型文件和服务发现文件读取前拒绝命名管道、设备等特殊文件；预览文件检查不占用业务 actor，取消及退出等待其停止。完整性读取模型资产，托管模型校验磁盘 manifest 与索引的一致性、制品身份、文件摘要及目录布局（拒绝额外资产和符号链接）；本地引用没有可信远端摘要。联网检查只验证选中的默认来源或镜像、现存凭据对指定仓库的元数据访问，不代表所有仓库/端点均可访问，不下载权重或加载模型。诊断导出保留安全错误码/阶段及分配器统计，不包含 token、私人对话或完整敏感路径；无法确认服务端检查停止时明确报告。

下载计划和运行预览统一使用四种资源状态：推荐配置、资源紧张、超出安全预算、无法可靠估算。推荐只表示预计余量，不承诺性能或绝对安全。下载前展示磁盘峰值、估算内存组成与条件；只读取小型配置和必要权重文件大小，不用仓库总大小当作运行内存。内存风险不禁止保存模型，原有磁盘保护仍有效。缺配置、未知架构或估算溢出不显示推荐。

运行预览解析实际有效输出参数，使用完整输入 token 上限与模型 context 的保守包络；实际 tokenizer/template 输入长度加载后另校验。不能从字符数保证精确 KV 需求，不静默缩短输入或输出。运行前由唯一 RuntimeCoordinator 重新检查预算、压力、驻留与固定状态，在高峰分配前预留；CLI、GUI、HTTP 和直接 Core 调用遵循同一规则。单 GPU 高峰执行，等待请求不重复预留 KV；共享驻留只计一次权重，已驻留模型不计新加载峰值。预览可能因其他请求或系统状态变化而失效。

运行中 macOS warning 压力暂停新任务，critical 请求取消生成/排队；只在后端真实停止/卸载后释放预留。空闲且未固定的模型可回收，固定模型不自动淘汰。normal 稳定 5 秒后恢复准入。加载与 GPU 同步不能保证即时中断，停止前仍显示占用；本机制不保证避免系统 OOM，不修改用户配置、删除文件或停止无关进程。
