## 人工验收操作

准备：这台机器已有上述产物和模型。先在终端定义：

```sh
MOX=/Users/neo/Code/personal/mox/.build/m1/mox
MODEL=/Users/neo/Code/personal/mox/.build/test-models/qwen2.5-0.5b-4bit
```

1. 中文一次性问答（R02/R04/R10）
   - 执行 `"$MOX" chat --model-path "$MODEL" --prompt '用一句话解释什么是海洋。' --max-tokens 48 --temperature 0`。
   - 预期逐步出现中文回复，stderr 有 loading/prefill/decode、token 统计与 finished；`echo $?` 为 0。自由文本不要求与报告相同，length 表示达到指定上限。
2. 多轮上下文（R09）
   - 执行 `"$MOX" chat --model-path "$MODEL" --max-tokens 128 --temperature 0`。
   - 第一轮输入 `Remember the word ocean. Reply briefly.`，第二轮输入 `What word did I ask you to remember?`。
   - 预期第二轮使用先前上下文，整个会话只出现一次 loading。模型质量可由用户评价；该 0.5B 模型不是高质量通用助手。
3. 停止并继续（R05/R09）
   - 执行 `"$MOX" chat --model-path "$MODEL" --max-tokens 2048 --temperature 0`，输入 `Write a detailed 2000-word essay about the history of mathematics.`。
   - 开始输出后按 Ctrl-C；预期提示等待停止、finished=cancelled、回到 `You>`。再输入 `What is 2 plus 2?`，应正常生成。空闲 Ctrl-C 或 Ctrl-D 退出，`echo $?` 为 0。
4. 清楚的失败（R01/R03）
   - 执行 `"$MOX" chat --model-path /tmp/mox-no-such-model --prompt hello`，预期 invalidModel，退出码 1。
   - 执行 `"$MOX" chat --model-path "$MODEL" --prompt hello --max-tokens 0`，预期 invalidParameters，退出码 2。不会下载或修改原模型。
5. 工程目录外运行与诊断（R10）
   - 执行 `cd /tmp`，然后 `"$MOX" chat --model-path "$MODEL" --prompt 'Say hello.' --max-tokens 8 2>/tmp/mox-m1-manual.log`。
   - 预期仍正常生成；查看 `cat /tmp/mox-m1-manual.log` 可获得 request ID、阶段与统计。自动脚本还验证了整套产物复制到临时 Unicode 路径以及禁止网络后运行。

任何场景失败：记录命令、退出码、stderr 和对应 request ID；必要时提供上面的 Unified Logging 文件。不要发送私人 prompt/回复或密钥。临时诊断日志可按需删除；CLI 不建立持久会话或模型库，无需清理业务数据库。测试模型可保留供复核，Mox 不删除引用目录。
