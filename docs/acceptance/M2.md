最终规则/集成/Unicode 测试 **53 项通过**；Release GUI **8 项通过**，Debug GUI **1 项通过**；另有 **1 项** prefill 输入长度核验。存储、HTTP 与故障夹具验证规则，真实模型由 GUI 和推理脚本验证，不相互替代。原生目录选择已有实测证据，自动 GUI 套件预置本地模型路径。

实际性能：

- 热生成吞吐中位数，128/512/2048 档为 **235.4 / 220.8 / 209.2 token/s**。原 M1 交付二进制在当前系统重跑为 232.5 / 220.7 / 212.4 token/s；下降比例为 -1.3 / 0.0 / 1.5%，均未触及 20% 调查门槛。M1 未用 M2 工具链重新编译，此对照不能分离编译器与架构影响。
- 18 个真实输出样本均达到目标；采样 RSS 最大 437,895,168 bytes。完整首内容延迟、启动耗时和逐样本统计见机器证据。
- 取消到完成等待：loading 0.334–0.336 秒；prefill 1.544–1.627 秒；decode 0.009–0.010 秒。loading/prefill 均在首内容前取消，之后再次生成通过。同步 MLX prefill 仍需等待官方回调；GUI 保持“正在停止”。
- GUI 停止呈现 20 次，p95 上界 **34ms**、最大 35.92ms；生成期间主 run loop 单次忙碌最大 **94.83ms**，低于 250ms；checkpoint p95 上界 38ms。测试包含历史页替换；回复呈现由自身状态决定，页面替换不保留已移出页的滚动布局。指标为鼠标事件到原生文本首次绘制，不包含显示器扫描；run loop 不等于 GPU 工作时间。
- 解码历史对照：同一工具链、官方 tokenizer 固定 Unicode 序列各档 3 次，8192 token 中位耗时由全前缀解码 39.13 秒降至批量解码 4.05 秒；首 token 即时，后续按 8 token/50ms 合并。该比较在工具链升级前测得，未冒充当前 Xcode 27 测量；当前规则测试验证解码一致性。

历史库每档运行 3 个独立读取进程，夹具写入进程不计入读取内存；耗时为中位数，RSS 为各读取进程峰值的最大值，**不是整个 GUI/MLX 的内存**。两档均证明摘要和新建不解码正文，详情仅读取当前 8 条（约 1MiB）；12/120 个有内容会话保持全部 240/2400 条回复，每次读取另新建一个空会话。

| --- | --- | --- | --- | --- |
| 30 MiB / 240 条回复 | 1.7ms | 9.7ms | 2.3ms | 15.2 MiB |
