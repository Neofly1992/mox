## 人工验收操作

以下步骤在交付的 Release App 上执行；AI 自测不代替用户反馈。

1. 打开交付 App，在“模型”点“获取模型…”，选 Hugging Face，仓库输入 `mlx-community/Qwen2.5-0.5B-Instruct-4bit`，版本 `main`；先点“检查模型”核对固定版本、文件数、下载量与峰值空间，再开始下载，在“下载任务”看进度，完成后返回模型页，点“查看详情”→“测试此模型”，发送一句话。应看到真实流式回答。
2. 换 ModelScope，仓库同上，版本 `master`；重复获取与聊天。两源版本不同、身份分开。若已有同源同版本，先选择另一个隔离数据目录或清理测试安装，不能把重复安装当成功。
3. 下载中暂停，退出 App 后重开，查看任务为 interrupted/paused，点继续；已完整校验文件保留，未完成文件可重下。取消后任务保留，点“清理未完成文件”才清理。
4. “添加本地目录…”选择已有模型，删除该引用后确认原目录仍在；托管模型点击“删除托管模型…”后应删除 Mox 管理的文件。正在推理时删除应提示 busy，不影响已发出的生成。
5. 在获取表单填自定义 HTTPS 同协议来源或镜像；错误地址要显示安全诊断。凭据仅输入到 Keychain，服务配置与导出诊断不得出现明文；更换镜像时原站凭据不能发送到镜像。

自动测试使用隔离目录；手工测试请记录模型仓库、版本、操作时间和可见错误。诊断可用 App“导出诊断…”；不要在报告中粘贴 token 或签名下载 URL。清理时只删除测试用的 Mox 数据目录/托管模型，外部本地模型目录由用户自行决定保留。
