# M3：获取与管理模型

状态：**待人工验收**；原独立审查 R1–R3 已在后续阶段定向复核，首版全仓新问题以 [2026-09-29 审查](../reviews/repository-2026-09-29.md)和[源码发布收口报告](../acceptance/source-release-2026-09-29.md)为准。AI 证据与缺口见交付报告，尚未人工验收。M2 R1–R3 已定向复核无阻塞；用户明确授权提前进入 M3，M2 完整人工验收仍未完成。本文规定要求，不表示实现或测试通过。

## 范围与用户行为

交付 HF / ModelScope 获取→持久任务→校验安装→模型管理→真实聊天的 GUI/CLI 闭环。模型页使用服务安装目录；获取子页接受来源、仓库地址、revision 和仓库内变体目录，先检查精确版本、文件数、下载量及峰值空间，再由用户开始下载；CLI 提供 `models plan`。下载任务独立于观察页面。来源/镜像与凭据在获取表单设置，并在模型页展示有效来源；CLI 可列出与切换默认来源。安装成功后可测试；失败保留旧版本，不自动更新、不转换精度。

不含 M4 标准协议、Pi、多模态实现、OCI、任意网站下载、转换量化或正式分发。新模型架构未通过已有 Core 资源估算时明确拒绝，不扩展推理范围。

## 责任与权威

- Domain：来源/模型引用、精确快照清单、校验类型、安装/任务/配置值类型；不携带凭据。
- Core：唯一模型管理用例；解析、任务生命周期、安装事务、alias、配置冲突、删除准入。ArtifactStore 负责路径、文件校验和原子目录提交；RuntimeCoordinator 继续唯一持有运行资源和 lease。
- Core 用例边界：`ModelLibraryService` 注入来源与凭据、运行 ports，持有完整配置事务、参数冻结、固定状态协调及删除准入；危险元数据操作不对 Core 调用方公开。`DownloadManager.open` 必须拥有可取消的后台恢复，生命周期准入覆盖创建、恢复、暂停、取消、丢弃与关闭；持久变更与 runner 等待分开，不能在 await 后产生第二个 runner。
- Sources：HF 官方 Swift SDK 与 ModelScope 薄适配；源元数据、下载定位、受控 URLSession/Keychain。网络失败转换为安全错误，不导出远端正文、签名 URL 或 token。
- Persistence：服务唯一写入的独立 SwiftData RuntimeStore；安装、任务和来源配置具有独立身份与有界查询，跨记录修改保持一致；数据库 record 不越过 actor。不能因一次进度更新重编码整个不断增长的模型库。App 对话库继续独立拥有。
- Server/Client：私有鉴权接口与值类型传输；CLI/GUI 不实现第二套安装/删除/配置规则。composition root 注入上述依赖。

独立审查 R3 的接口边界：配置、安装/任务摘要列表、单项详情分离；列表采用稳定顺序和有界分页，摘要不内联文件清单，文件清单详情也有分页或明确大小准入。任何合法库增长不得使配置、列表、进度、删除接口越过客户端单响应限额。GUI/CLI 按页查询，不能在客户端重新无界拼装全库。此契约已在源码中实现；大于 1 MiB 合法库的服务级回归见 M3 验收报告。

## 身份、来源、凭据

`registryID + repository + exactRevision + variantDirectory` 唯一确定来源快照；artifact ID 是规范化有序编码的 SHA256，不含镜像地址或别名。installation UUID 用于管理，alias 全库唯一；本地引用身份不冒充远端来源。repository 按分段处理，拒绝空段、点段、控制符与 URL 注入；地址仅接受已配置来源 origin 对应仓库，不能自动把任意站点设为可信源。

CLI 省略 `--provider` 与 `--endpoint` 时使用有效 defaultRegistry；显式 provider 则优先选该协议的默认来源。selector 与解析后的不可变 revision 分开保存；变体是仓库内模型根目录，不靠名称猜量化。固定 commit 不做自动跟踪。镜像替换访问端点但不改变 registryID；GUI 获取表单应预填已配置镜像，不可因再次获取而清除。配置修改增加 revision，expectedRevision 不符返回 409。

origin / mirror 必须为 HTTPS、无 userinfo/query/fragment；凭据按 registry 与精确 origin（scheme/host/port）存 Keychain。每次更新写入新的凭据引用，元数据保存成功才启用；配置冲突或保存失败清理未使用的新引用，旧引用不能被过期请求覆盖。不使用环境 HF token 或用户全局 token/cache。镜像需独立授权的凭据；跨 origin 重定向不带 Authorization/Cookie，拒绝 HTTPS 降级；分页链接不得扩散 token。Keychain 失败明确返回错误，绝不落明文或降级匿名。导出仅引用和有效配置 provenance。

HF 使用官方 `swift-huggingface` 0.11.0 并锁定于 `Package.resolved`；ModelScope 参考官方 `modelscope_hub` commit `0b2a3bacef4cbeccfd9a64545149d56cb1bb98a1`。真实响应显示单文件 Revision 是文件最后修改版本，不能当仓库 HEAD；ModelScope 移动分支通过官方 commits API 解析为仓库精确 commit，再用该 commit 请求文件清单。解析失败即拒绝获取，不伪造精确 revision。

## 任务与恢复

`resolving → downloading → verifying → committing → installed`；下载可进入 paused、failed、interrupted 或 cancelled。暂停保留任务/已验证文件；取消停止工作并保留明确 cancelled 状态；丢弃单独清理未安装的该任务目录，GUI「取消并清理」串行执行两步。观察断连不取消。安装临界区开始后等待提交完成，不在 rename/save 中间响应清理。

计划在第一次下载前持久化：operation UUID、不可变快照、文件路径/大小/校验算法与值、阶段、已验证字节、安全错误。重启不自动重复生成或悄悄换 revision；未完成任务在恢复后为 interrupted，可显式恢复。服务探活先于耗时校验；`libraryRecovery` 和 checking 区分可连接与模型就绪，目标模型通过本次进程的完整性校验才可推理。恢复先校验已有完整文件；当前实现按文件重下未完成文件，已验证文件复用，不声称支持字节级断点续传。

未知总量显示已完成字节和阶段，不显示虚假百分比。网络/凭据/空间/完整性/存储错误分别提示；hash 错误不通过重试跳过校验。单流 Range 若实际采用，必须验证 206 Content-Range、offset、validator、长度；200 重下，416 重新检查或重下，不直接拼接未知响应。无需构造并行 Range 引擎。

## 原子安装与一致性

1. 检查计划路径、重复与大小溢出，选择 config、tokenizer、template、权重/index 和必要资产，拒绝不完整布局；获取前展示已知总量与含最大单文件临时副本的峰值空间，系统可用容量未知时明确显示，架构/权重兼容性在下载后最终确认。
2. 同文件系统 `staging/<operationID>` 下载。空间预留包括临时文件/cache/安装副本；ENOSPC 可恢复，不删除已安装版本。
3. 有界分块校验大小与真实 digest：SHA256 与 Git blob SHA1 区分；opaque ETag 仅恢复 validator。本地 SHA256 标注 local，不能当服务端证明。拒绝路径越界、符号链接、重复/大小写折叠冲突和不受支持文件类型。
4. 调用现有 LocalModel 校验权重/index/资源估算，复用唯一模型有效性规则。写 schemaVersion=1 manifest，包含来源和校验 provenance、不含凭据；同步文件后原子 rename 至 `artifacts/<artifactID>`，绝不覆盖快照。
5. 显式保存 SwiftData 安装和 alias。rename 后保存失败不删除已提交文件；启动扫描可信 prepared manifest 修复索引，已有索引无文件则 missing，不能显示 ready。崩溃注入覆盖 rename/save 前后。

## 管理、删除与 lease

list/show/load/unload/remove/select 在 CLI/GUI 共用服务。引用导入保存规范路径/指纹，移除只删记录；重复导入同一路径打开已有引用，失败不能提前切换测试模型。托管删除明确说明文件范围；文件已在外部丢失时仍可清除记录和完成重启恢复。管理器在运行准入前冻结安装与 artifact；删除和新请求准入共享互斥边界，使用中返回 busy，不取消其他客户端。卸载完成并阻止新 lease 后才能删除文件。同一 registry/repository/variant 的当前 alias 在新版本成功提交后原子指向新安装；旧版保留精确版本 alias 并可重新选为当前。在途请求与历史仍使用冻结路径。仅清理 Mox 自有无引用 cache，绝不触碰全局 HF cache。

默认参数按显式请求 > 模型设置 > 有效全局 > 产品默认冻结；启动覆盖不偷偷持久化，GUI/CLI 显示 provenance。设置更新携带 expected revision。
