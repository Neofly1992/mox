## 非目标

不含 OCI registry、自研并行 Range 引擎、模型转换/量化、全自动模型适配或多模态推理。

## 出口

所有必需要求有通过证据，按 CONTRIBUTING 创建 `docs/acceptance/M3.md`，附精确版本/命令/产物、限制和人工步骤。未测必需项不得标待验收。用户明确验收后才标已验收。

## 人工验收场景

1. 从 HF 与 ModelScope 分别获取小模型并聊天。
2. 配置同协议来源/镜像，检查有效设置和错误信息。
3. 暂停下载、重启、恢复，最终可加载。
4. 导入外部目录再移除，原文件仍在。
5. 查看空间占用，删除托管模型；错误可诊断。

## 实施前需细化

来源语法与转义、模型搜索和变体 UI、完整安装 schema、各 provider 不可变 revision 能力、恢复的可保证边界、缓存 GC/空间计算及 config CLI。
