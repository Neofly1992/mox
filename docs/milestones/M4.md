# M4：协议与 0.1 本机原型验收

状态：规格概要。用户明确 0.1 为自己做功能验证；不要求 Codex、Pi、开发者付费账号、签名公证或 Homebrew 发布。

## 入口

M3 已验收；进入编码前细化 OpenAI Chat Completions/Anthropic Messages 的 DTO、事件序列与错误映射，核验官方协议和选定 SDK 的当前行为。

## 人工验收与出口

1. 本地打开 App，选择来源下载模型后聊天。
2. 停止长回复、再次生成、重启查看历史与模型。
3. 开启 API，按报告运行已准备的两种协议测试命令和工具往返示例。
4. 模拟错误凭据或服务中断，查看诊断并恢复。

全部必需项有证据，创建 docs/acceptance/M4.md；用户明确通过后标记“0.1 原型已验收”。无外部发布动作。
