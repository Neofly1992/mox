# P1：公开分发（0.1 原型之后）

状态：后续规划，尚未启动。入口：原型验收通过，用户明确决定公开分发。

## 实施前明确

发行版本、Apple Developer Program 身份、bundle ID、发布仓库与下载位置、是否同时提供自有 Homebrew tap、最低系统与干净测试环境。无需现在购买或申请。

## 出口要求

- P1-R01：arm64 App/worker/Metal bundle 完整，Developer ID 签名、Hardened Runtime、公证及相应验证；安装不要求用户有 Xcode/Python/brew。
- P1-R02：干净账户/目标支持系统、外置模型目录、Keychain、首次启动/卸载边界验证。
- P1-R03：若选择 Homebrew，formula/service/cask 的安装、start/stop/restart、App 共存验证；自有 tap 无需等待主仓收录。
- P1-R04：构建 CI、依赖锁定、许可与校验信息、发布说明和支持范围完整；精确产物人工验收通过，获得外部发布授权后发布。

按 CONTRIBUTING 完成 docs/acceptance/P1.md。发布费用、身份、凭据均不能伪造；凭据不进文档。具体操作与 CI 配置在启动本阶段时细化。

## 后续 agent 隔离候选

Apple container 运行轻量 Linux VM，当前官方支持 macOS 26。可探索 Pi 和工具在容器运行、通过受限连接调用 macOS 宿主 Mox API；不将 macOS MLX/Metal 推理搬入 Linux。需要设计工作目录挂载、网络/凭据、生命周期与安装方式；宿主 loopback 不自动等于容器可访问，不能直接开放所有网卡来省事。该方向是候选，不是 P1 或 0.1 必需项。
